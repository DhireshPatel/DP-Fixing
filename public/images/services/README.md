Service images are currently referenced as remote Unsplash URLs (configured in
`scripts/seed.js` and editable from Admin → Services) so the project works
out-of-the-box without any binary assets in this repo.

For production, download/license your own professional service photos and
place them here (e.g. `fan-installation.jpg`), then reference them as
`/images/services/fan-installation.jpg` when adding/editing a service from
the admin panel.
